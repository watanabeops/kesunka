# 申し送り：「活動記録」の改名と葉アイコンの採用

> **対応済み（KESUNKA v1.1.1 / KESUNKA MAMA v1.1.0）。この文書は経緯の記録として残しています。**
>
> - 呼び名は **「学びの日々」** を採用（4-1の候補「学んだ日々」ではなく、依頼により決定）
> - 4-2の「記録なし」は**据え置き**。「学んでいない日」は勉強アプリでは咎めるように読まれ、
>   「お休み」は記録が無いだけの日に休んだと断定してしまうため、ログの状態を述べる表現にした
> - KESUNKA MAMA側には「活動記録」も📊も無かったため、同じ性格を持つ日別ビューの見出しを
>   「直近7日間の学習時間」→「🌱 学びの日々（直近7日）」に変更した
> - 作業中に表示の不具合を2件発見し、あわせて修正（一覧行が潰れてタグが見切れる／
>   月ラベルの折り返し）。詳細は index.html 冒頭の変更履歴 [v1.1.1] を参照

Guevara（日記アプリ）で決めた変更を、KESUNKAにも反映するための申し送りです。
Guevara側は **v2.0.9** で実施済み。この文書だけで作業できるようにまとめてあります。

---

## 1. 背景と結論

「活動記録」という語が業務報告のような硬さを持っていて、アプリの語りかけと合って
いませんでした。Guevaraでは以下に変更しています。

| 箇所 | 変更前 | 変更後 |
|---|---|---|
| ボタン | 📊 活動記録 | 🌱 書いた日々 |
| 見出し | 活動記録（過去1年） | 書いた日々（過去1年） |
| サマリー | 過去1年間で N 日 記入 | 過去1年で N 日 書きました |
| ツールチップ（記録なし） | 記入なし | 書いていない日 |

絵文字を📊（棒グラフ＝集計表の顔つき）から🌱（葉）に変えたことで、ヒートマップの
緑のセルと色が揃い、画面全体がやわらかくなりました。

### 「草」を使わなかった理由

この機能はGitHubのcontribution graph（通称「草」）が由来ですが、**いまの日本語では
「草」は笑いの意味（www→草）が主流**のため、ラベルには採用していません。葉のマークで
由来だけ残す、という判断です。KESUNKAでも同様に「草」は避けてください。

---

## 2. 確認済みの前提

作業前に調べた結果、KESUNKAはGuevaraと同じ条件が揃っています。

- **ヒートマップの基準色が同一** — 両アプリとも `CONTRIBUTION_BASE_COLOR = '#2ecc71'`
  （KESUNKA: `index.html` L2427）。したがって🌱はGuevaraと同じように馴染みます。
- ボタンの隣に `🔥 0日` のストリークバッジがありますが、🌱（育つ）と🔥（継続）は
  並んでも喧嘩しません。

---

## 3. KESUNKAでの変更箇所

KESUNKAは**単一HTMLファイル**（`index.html`にCSS/JSがインライン）です。
行番号は v1.1.0 時点のもので、編集すればずれます。文字列で検索してください。

| 行 | 現在の内容 | 変更内容 |
|---|---|---|
| L1533 | `<span>📊</span> <span>活動記録</span>` | 絵文字と語を差し替え |
| L1461 | `<h2>活動記録（過去1年）</h2>` | 見出しを差し替え |
| L2527 | `` `過去1年間で ${writtenDays} 日 学習（合計${totalMinutes}分）` `` | 語調を合わせる |
| L2492 | `` `${c.dateStr}（${WEEKDAYS_JA[c.weekday]}）: 記録なし` `` | 下記4-2の判断による |
| L2424 | `* 活動記録（GitHub風ヒートマップ）：合計学習時間（分）ベース` | 内部コメントを表示に合わせる |

ボタンはヘッダーではなく**目標エリア（goal-panel）内**にあります（v1.0.8で移動済み）。

### 変更しないもの

内部の識別子（`contributionSummary` / `.contribution-cell` / `renderContributionGraph`
など）は **contribution* のまま残す**方針です。GitHubのcontribution graph由来の名前で、
表示名だけの変更に40箇所近い改名は割に合わないためです。Guevara側も同じ判断をし、
その旨をコード内コメントに残しています。

変更履歴の過去のエントリ（L20・L80の「活動記録」への言及）も、**当時の事実の記録なので
書き換えません**。

## 4. KESUNKA側で判断が必要な点

**そのまま流用できない箇所が2つあります。** ここは決めてから着手してください。

### 4-1. 「書いた日々」は使えない

KESUNKAは学習ログなので「書く」ではありません。素直な対応は **「学んだ日々」** です。

```
ボタン    🌱 学んだ日々
見出し    学んだ日々（過去1年）
サマリー  過去1年で N 日 学びました（合計M分）
```

他の候補：続けた日々／積み重ね。いずれも「記録」「活動」の管理っぽさを避ける狙いです。

### 4-2. 「記録なし」をどうするか

Guevaraでは「書いていない日」に変えましたが、**KESUNKAは勉強アプリなので、空のセルに
「学んでいない日」と出すと咎めるように読まれる恐れがあります。**

- `記録なし` のまま据え置く（無難）
- `お休み` にする（やわらかい）
- `学んでいない日` にする（Guevaraと完全に揃うが、上記の懸念あり）

使う人の年齢や、保護者向け要約を送る機能があることを踏まえて決めてください。

- 旧表記が画面に残っていないかを確認（`document.body.innerHTML.indexOf('活動記録')`）。
