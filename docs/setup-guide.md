# セットアップガイド

KESUNKAは https://watanabeops.github.io/kesunka/ で公開済みです。このドキュメントでは、公開済みのアプリをiPadなどの端末で使い始める手順と、更新時の注意点を説明します。

## 1. iPadのホーム画面に追加する

1. iPadの**Safari**（他のブラウザではなく必ずSafari）で https://watanabeops.github.io/kesunka/ を開く
2. アプリが正しく表示されることを確認する
3. 画面上部（または下部）の共有アイコン（四角から上に矢印が伸びたマーク）をタップ
4. メニューから「ホーム画面に追加」を選ぶ
5. 名前（KESUNKA）を確認して「追加」をタップ
6. ホーム画面にアイコンが追加されるので、そこから起動する

ホーム画面から起動すると、Safariのアドレスバーなどが表示されない、アプリのような画面で使えます。一度開いておけば、オフライン（機内モードなど）でも記録の追加・閲覧ができます。

> **⚠️ 追加したあと、このアイコンを削除しないでください。**
> iOSでは、ホーム画面に追加したWebアプリを削除すると、そのアプリが持っていた学習記録
> （localStorage）も一緒に消えることがあります。アイコンの絵柄を新しくしたい、更新が
> 反映されない、といった理由での削除・再追加も同じです。
> 追加したら、続けて「3. バックアップと共有を設定する」でクラウドバックアップを
> 有効にしてください。それが唯一の保険になります。

## 2. PC・スマートフォンのブラウザでそのまま使う

ホーム画面への追加は必須ではありません。上記URLをPCやスマートフォンのブラウザ（Chrome、Safariなど）で開けば、通常のWebページとしてそのまま全機能を使えます。データはそのブラウザ内（localStorage）に保存されるため、次回も同じ端末・同じブラウザで開けば記録が残っています。

ブラウザのプライベート/シークレットモードで開いたり、閲覧データを消去したりすると記録が消える点、また別のブラウザ（例: SafariとChrome）で開くとそれぞれ別のデータになる点にご注意ください。

保護者用ビューア（KESUNKA MAMA）も同様に、インストール不要でブラウザから開けます。

```
https://watanabeops.github.io/kesunka/mama.html
```

## 3. バックアップと共有を設定する

ヘッダーの「☁️ バックアップ」から、独立した2つのスイッチを設定します。どちらもFirebase（Googleの無料サービス）を使い、Firebase設定とキーは共通です。設定手順は [docs/firebase-setup-guide.md](firebase-setup-guide.md) を参照してください。

**クラウドに記録を保存する（バックアップ）**

学習ログの全履歴をFirestoreに保存します。**端末のデータが消えても、キーを入れれば全履歴が戻ります。** 記録を守るための機能なので、特別な理由がなければオンを推奨します。

**保護者に共有する**

保護者が別の端末から学習状況を閲覧できるようにします。今日の記録についてはメモの内容も表示されます。バックアップだけをオンにして、共有はオフにすることもできます。

### バックアップキーについて

キーは「☁️ バックアップ」画面に表示され、コピーボタンで取得できます。保護者への共有コードと共通です。

- **必ず控えを残してください。** 端末が消えたとき、記録を戻せる唯一の手がかりです
- キーを知っている人はデータを読み書きできます。パスワードと同じ扱いにしてください
- 保護者側（KESUNKA MAMA）にも同じキーを入力するため、控えが2箇所に残ります

### 別の端末で復元する

1. 新しい端末で https://watanabeops.github.io/kesunka/ を開く
2. 「☁️ バックアップ」を開き、Firebase設定とバックアップキーを入力して保存する
3. 全履歴が自動で復元されます（起動時にこの端末が空であれば、クラウドの記録を読み込みます）
4. 自動で戻らない場合は「クラウドから復元」を押してください

なお、**この端末に記録が無い状態でクラウドを上書きしてしまわないよう**、アプリ側で保護しています。0件の状態では書き込まず、復元を促します。

### バックアップが動いているかの確認

画面上部に赤い警告バナーが出ていなければ、バックアップは有効です。バナーには2種類あります。

- 「記録がこの端末の中にしかありません」 — 未設定。バナーを押すと設定画面が開きます
- 「クラウドに保存できていません」 — 設定済みだが保存に失敗している。通信状況とFirestoreのルールを確認してください

- [ ] 公開URLでアプリが正しく開ける

- [ ]（共有を設定した場合）保護者側の画面が、子ども側の記録後しばらくして自動更新される

## 5. こまったときは

**ページが真っ白になる／404エラーが出る**
一時的な反映遅延の可能性があります。少し時間を置いてから再読み込みしてください。

**アイコンが表示されない・ホーム画面に追加できない**
`icons/` フォルダに `apple-touch-icon.png` `icon-192.png` `icon-512.png` `icon-512-maskable.png` の4つが入っているか確認してください。KESUNKA MAMAは `manifest-mama.json` を参照します。
なお、**ホーム画面に追加済みのアイコンは、追加した時点の絵柄を保持します。** 新しい絵柄にするには削除して追加し直す必要がありますが、その操作でデータが消える恐れがあるため、上記の警告を必ず読んでください。

**学習記録が消えた**
まずSafariで直接 https://watanabeops.github.io/kesunka/ を開き、記録が見えるか確認してください（ホーム画面のアプリとSafariでは、iOSのバージョンによって保存領域が別々のことがあります）。見えたらその場でJSONバックアップを保存してください。
クラウドバックアップを設定済みであれば、「☁️ バックアップ」→「クラウドから復元」で戻せます。設定していなかった場合、端末のバックアップ（iCloud等）からの復元以外に手段はありません。

**保護者側の「今日の学習時間」に「今日の記録はまだ届いていません」と出る**
不具合ではありません。要約はお子さんが記録を追加・編集したときにしか送信されないため、その日の記録がまだ無い状態です。以前は前日の数字が「今日」として表示されていました（MAMA v1.1.1で修正）。

**iPadでホーム画面に追加しても、ブラウザのまま表示される**
Safari以外（Chromeなど）で開いて追加していないか確認してください。iPadでは必ずSafariから操作してください。

**保護者側が「データ待ち」のまま変わらない**
子ども側・保護者側の両方で、Firebase設定（JSON）と共有コードが一字一句完全に一致しているか確認してください。詳しくは [docs/firebase-setup-guide.md](firebase-setup-guide.md) の「動作確認のしかた」を参照してください。

## 6. アプリを更新するとき（開発者向け）

このリポジトリの `main` ブランチにファイルをコミットすると、GitHub Pagesが自動的に再ビルド・再公開します（数分かかることがあります）。GitHubの「Add file → Upload files」で該当ファイルを上書きアップロードし、コミットするだけで反映されます。

PWA版は端末に一部のファイルを保存（キャッシュ）する仕組みがありますが、**v1.0.8以降、ページ遷移はネットワーク優先になっています。** 更新後にアプリを開き直せば、それだけで新しい版になります。強制リロードもキャッシュ削除も不要です。切り替わりのタイミングで、1回目が古いまま・2回目で最新になることがあります。

> **⚠️ 「ホーム画面のアイコンを削除して追加し直す」は行わないでください。**
> iOSでは、ホーム画面に追加したWebアプリを削除すると、そのアプリが持っていたデータ
> （localStorage）も一緒に消えることがあります。**このドキュメントには以前、更新が
> 反映されないときの対処としてこの手順が書かれており、実際にそれで全履歴が失われました。**
> アイコンの絵柄を変えたい場合も同じです。どうしても必要なときは、必ず先に
> クラウドバックアップを有効にするか、JSONバックアップを保存してください。

`sw.js` 内の `CACHE_NAME` は、**v1.1.0以降、更新のたびに変更する必要はありません。** ページ遷移はネットワーク優先、アイコンやmanifestはキャッシュ優先＋裏で更新（stale-while-revalidate）になっているため、値を変えなくても更新が届きます。変更するのは、キャッシュを全部捨ててやり直したいときだけです。

### 表示上のバージョン

`index.html` と `mama.html` は、それぞれ独立した版番号を持ちます。更新時は以下の3箇所（mama.htmlは2箇所）を揃えてください。

- `<title>`（index.htmlのみ）
- `.version-badge` の表示
- `APP_VERSION` 定数（index.htmlのみ。クラウドバックアップに記録されます）

採番はパッチ0〜9で運用し、9の次でマイナーを繰り上げます。あわせて各HTML冒頭のコメントに変更履歴を追記してください。
