# KESUNKA

中高生向けの勉強ログPWA（Progressive Web App）と、その学習状況を保護者が閲覧できる専用ビューア「KESUNKA MAMA」です。

## 公開URL

| アプリ | URL |
|---|---|
| KESUNKA（本体・お子さん用） | https://watanabeops.github.io/kesunka/ |
| KESUNKA MAMA（保護者用ビューア） | https://watanabeops.github.io/kesunka/mama.html |

いずれもインストール不要で、上記URLをブラウザで開くだけで使えます。KESUNKAはiPadのSafariから「ホーム画面に追加」することで、アプリのような全画面表示・オフライン利用が可能になります（手順は[docs/setup-guide.md](docs/setup-guide.md)参照）。

> **⚠️ ホーム画面に追加したアプリを削除すると、その端末に保存された学習記録も一緒に消えることがあります。**
> iOSの仕様によるもので、アイコンを付け替える目的であっても削除・再追加はしないでください。
> 実際にこれで全履歴を失った事例があり、その対策としてクラウドバックアップを実装しています。
> 削除する必要がある場合は、必ず先にクラウドバックアップを有効にするか、JSONバックアップを保存してください。

## 主な機能

### KESUNKA（本体）

- 科目（固定12タグ）と時間（30〜180分）をタップで選んでセッションを記録。メモも任意で残せる
- 日別の目標設定・連続記録（ストリーク）表示
- 過去1年の学習をヒートマップで見る「学びの日々」
- **クラウドバックアップ** — 学習ログの全履歴をFirebase Firestoreに保存し、端末が初期化されても
  バックアップキーの入力だけで全履歴を復元できる（任意機能）
- TXT/JSONでの手動バックアップ・読み込み
- Firestoreを使った、保護者への一方向の学習状況共有（バックアップとは別の任意機能）
- ダークモード対応、PWA（ホーム画面追加・オフライン利用）対応

### KESUNKA MAMA（保護者用ビューア）

- 今日の学習時間・目標達成・科目別の内訳と、**今日の記録一覧（科目・時間・メモ）**
- 直近7日間の学習時間（棒グラフ＋日ごとの一覧。日付・時間・目標達成・科目内訳）
- 今週の合計・達成率、連続記録、科目別の学習時間（直近7日）
- 閲覧専用。書き込み機能は持たない

## データとプライバシー

Firestoreへの保存は、**独立した2つのスイッチ**で制御します。どちらもオフのままなら、記録は端末内（localStorage）だけに保存され、外部には一切送信されません。

**クラウドバックアップ（`studylog_logs`）**

オンにすると、**学習ログの全履歴（すべてのメモを含む）**がFirestoreに保存されます。記録の正本をクラウドに置き、localStorageは表示用のキャッシュとして扱う構成です。端末の初期化やホーム画面からの削除で端末内のデータが消えても、バックアップキーを入力すれば全履歴を復元できます。

**保護者への共有（`studylog_shared`）**

オンにすると、要約データが一方向に送信されます。内容は「今日/週の合計時間・科目別の内訳・目標達成率・連続記録」「直近7日間の日ごとの学習時間と科目内訳」、そして**今日の記録（科目・時間・メモ）**です。昨日より前のメモは送信されません。

**キーの扱い**

バックアップキー（＝保護者への共有コード）は、認証の代わりにパスワードとして機能します。**キーを知っている人は、そのデータを読み書きできます。**とくにバックアップをオンにしている場合、キーがあれば全履歴を読めることになるため、むやみに他人へ渡さないでください。同時に、**キーを失うと復元できません。**控えを残してください。

詳細は [docs/firebase-setup-guide.md](docs/firebase-setup-guide.md) を参照してください。
